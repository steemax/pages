# Engineering Notes

GitHub Pages публикуется из каталога `docs/`.

Структура:

```text
docs/
  index.html
  styles.css
  articles/
    infra-agent/
    kubevirt-dev-cloud/
```

Каждая статья хранится вместе со своими `styles.css`, `app.js` и `assets/`, поэтому сборщики проектов могут обновлять их независимо.

Публичные адреса:

- `https://steemax.github.io/pages/`
- `https://steemax.github.io/pages/articles/infra-agent/`
- `https://steemax.github.io/pages/articles/kubevirt-dev-cloud/`
